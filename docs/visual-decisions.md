# Aurora 视觉决策

## macOS 主应用图标

Aurora 在访达和程序坞使用青蓝折带 A 的 **77% 留白版**。以 1024 × 1024 px 的图档为准，A 的可见轮廓为 648 × 648 px，白底为 840 × 840 px。A 占白底宽度的 77.1%，白底内上下各留 96 px，约占白底高度的 11.4%。

打包脚本将[定稿图标](../desktop/Platform/Mac/Assets/Aurora.icns)放入 `Aurora.app/Contents/Resources/Aurora.icns`，供主应用的 `CFBundleIconFile` 使用。

# Aurora 交互设计

这份说明对应随附的 Windows 和 macOS 视觉原型。页面切换、表单联动、菜单和提示可直接操作。设备、地址和服务状态均为示例，连接桌面、文件传输、观看模式、终端、端口映射、复制地址、安装、登录、服务重启、保存均通过原型反馈演示。设置值会随原型会话保留，重新载入页面会恢复示例值。

## 导航

启动后进入「我的设备」。侧栏从上到下放 Tailscale 账户、「我的设备」「本机被控」，底部放「设置」，其下是「更多」。账户页也显示异地连接状态。进入「全部配置项」时，左栏仍高亮「本机被控」，页标题右侧放带左箭头的「本机被控」返回动作。侧栏最大为 184 px，最窄档只显示图标并保留辅助技术可读的名称。macOS 原型还可用 ⌘+, 打开设置。

「更多」用三道横线图标，菜单在侧栏右侧展开，与侧栏右缘相距 6 px，菜单底边与按钮底边对齐。菜单依次包含「检查更新」「开源地址」「帮助」「反馈」「关于」。「开源地址」使用 GitHub 标志并打开项目仓库。「帮助」直接打开项目使用说明。「反馈」进入应用内页面。「检查更新」在草稿中演示检查中和检查结果。[展开截图](screenshots/components/sidebar-more-menu.png)

点「检查更新」后，左侧图标在原位切换成加载环，文字改为「正在检查…」。检查完成且已是最新版本时，还原菜单项并收起菜单，在应用窗口中央显示「当前已是最新版本」。提示保留 **3 秒**后自动淡出。提示没有按钮，鼠标和键盘可继续操作界面。开启「减少动态效果」时，加载环静止，提示直接显示和消失。[查看加载状态](screenshots/components/update-checking.png) · [查看提示截图](screenshots/components/update-current.png)

## 关于

从「更多 → 关于」进入应用内页面。顶部图标和项目名、版本号对齐，应用介绍在下方另起一段。「项目信息」和「主要组件」的标题位于各自卡片外上方，距卡片 6 px，与卡片左缘对齐。项目信息卡片包含作者、开源仓库和 GPL-3.0-only 许可。主要组件卡片列出 Moonlight、Sunshine 和 Tailscale 的用途及上游链接。宽窗和窄窗都将板块按内容区全宽上下排列，窄窗可滚动。原型使用项目当前版本 **0.8.0**。[Windows 关于页](screenshots/components/about.png) · [macOS 关于页](screenshots/macos/28-about.png)

## 系统托盘与菜单栏

两端菜单依次提供打开、设置和退出，仅在退出前放一条分隔线。「打开极光」恢复并聚焦主窗口，Windows 的「设置」与 macOS 的「设置…」都直接进入应用设置，「退出极光」结束应用。三项无需登录即可使用。[Windows 托盘](windows.md#托盘右键菜单) · [macOS 菜单栏](macos.md#菜单栏右键菜单)

「设置 → 界面 → 极光窗口」提供「关闭窗口时」。Windows 默认「最小化到托盘」，macOS 默认「隐藏到菜单栏」，都可改为「退出极光」。「恢复默认设置」位于设置选项卡行右侧，恢复该偏好和其他应用设置。主窗口最大化和全屏时仅将外框四角切换为直角，还原后外框恢复圆角。工作区始终沿用[统一的圆角与边距](layout.md#窗口与导航)。[Windows 窗口设置](screenshots/pages/18-window-preference.png) · [macOS 窗口设置](screenshots/macos/23-window-preference.png)

## 我的设备

[查看设备页截图](screenshots/pages/01-devices.png) · [查看更多工具菜单](screenshots/components/device-power-menu.png)

- 列表显示正在运行极光的设备，以及本机已识别过的同账号极光设备。普通 Tailscale 节点不列出，识别过的设备离线时继续显示。状态在壁纸左上角，设备名与地址在左下角。两类地址同一行，依次写「局域网」和「Tailscale」。只有一种地址时显示该项。
- 卡片优先显示已缓存的对端主屏幕壁纸缩略图，首次无缓存时用用户选的默认壁纸库。首张为晴空山谷，其他设备沿用同一组壁纸。正式应用仅在「我的设备」位于前台时检查更新，每台在线设备通常间隔两分钟，结束远控后额外检查一次。切到后台取消检查，设备离线时保留上一张缓存。缓存缩略图与默认壁纸共用同一图层。离线时在壁纸上叠 30% 不透明度的 #FBFBFB，置于底部暗渐变下方。恢复在线后显示原色，在线但串流不可用时也显示原色。[默认壁纸和图五取景规则](assets/README.md#设备壁纸)
- 有可用串流服务时，点击壁纸区域连接该设备。白底栏依次放「文件传输」「观看模式」「终端」「端口映射」和四宫格「更多工具」。每个按钮只作用于当前卡片。
- 串流可用的「在线」状态用蓝色实心点。未检测到串流的设备仍显示「在线」，改用琥珀色空心点，悬停状态标记可查看原因。「离线」用灰色空心点。后两种状态的壁纸区域和前四项操作不可用，仍可从「更多工具」查看并复制已有地址。
- 四宫格「更多工具」先列出当前设备可复制的地址，末尾依次放「重启」「关机」。各行共用 16 px 图标列，图标和文字相隔 8 px。两组留 6 px 空隙。离线或远程电源操作不可用时，文字与图标一起使用 #8390A1，悬停和键盘聚焦可查看原因。是否可用以当前设备的管理能力为准。
- 菜单优先向上展开，右边缘对齐四宫格按钮。可用空间不足时调整方向，保持菜单在窗口内。菜单用纯白背景、1 px #DBE2ED 描边和柔和阴影，宽至少 168 px，圆角 9 px，内边距 5 px。菜单项最小高度 32 px、字号 13 px、圆角 6 px。悬停铺 #E8EDF4，键盘焦点使用 2 px 品牌蓝轮廓。展开时四宫格用 #E2E7EF 表示状态。[在线菜单](screenshots/components/device-power-menu.png) · [离线菜单](screenshots/components/device-power-menu-offline.png)
- 点击任一电源操作，先收起菜单，再在主窗口中央确认。标题带设备名，如「要重启『书房主机』吗？」或「要将『书房主机』关机吗？」。正文说明会断开连接并提醒保存远端工作，关机时提示要重新开机才能再连接。默认聚焦「取消」。取消或按 Esc 都关闭弹窗，焦点回到原卡片的「更多工具」。确认按钮明确写「确认重启」或「确认关机」，沿用浅红危险按钮。请求受理后提示已发送，设备状态由实际连接回报更新。原型的确认只演示交互。[重启确认](screenshots/components/device-restart-confirm.png) · [关机确认](screenshots/components/device-shutdown-confirm.png)
- 标题右侧的刷新图标用于重新检查设备列表，操作结果显示在标题与卡片之间。已登录的空列表提示在另一台设备上打开极光，并在卡片中央放置「检查 Tailscale」实心蓝色主按钮。按钮沿用「前往登录」的高度和圆角，使用纯文字。

### 独立串流窗口

点在线设备的壁纸进入独立串流窗口。设备列表与设置继续留在主窗口，断开后回到该设备卡片。连接中、已出画、连接失败共用单行顶栏和画面容器。窗口化默认用可自由进出画面区的桌面指针，控件菜单可以切换到相对鼠标。[串流窗口规格、独立原型与三态截图](stream-session.md)

## 本机被控

[查看本机被控页截图](screenshots/pages/02-host.png)

- 「这台电脑」卡片展示 Sunshine 状态，并用「允许本机被控」开关启停由极光托管的被控服务。开启后启动服务，就绪时显示局域网地址以及已登录的 Tailscale 地址。地址可用旁边的图标复制。
- 关闭开关时，在窗口中央弹出确认，说明远控会话会断开。默认聚焦「取消」，取消或 Esc 保持开启，确认关闭后才收起地址和设置。已保存设置与配对记录保留。「重启 Sunshine」继续位于常用设置，用于应用已保存的配置。macOS 首次启用的屏幕录制和辅助功能授权流程继续适用。[Windows 常用设置](screenshots/pages/02-host.png) · [关闭被控确认](screenshots/components/disable-host-confirm.png) · [macOS 首次授权](screenshots/macos/24-host-permissions.png)
- 浏览器原型默认使用「内置托管」。在原型调节器的「Sunshine 运行方式」中可切换到「独立 Sunshine（参考）」，查看原有的「打开 Sunshine 原版设置」、创建或登录管理账号和受平台支持的凭据流程。[独立 Sunshine 创建管理账号旧例](screenshots/pages/19-sunshine-create-account.png)
- 标题右侧图标重新检测被控服务。检测结果出现在本页的反馈区域。
- 「常用设置」包含被控电脑显示名和将本机声音发送到主控端。「全部配置项」从该卡片进入。
- Sunshine 的常用设置与全部配置项均自动保存。下拉和开关更改即保存，文本停输约 650 ms 后保存。成功反馈为「已保存。重启 Sunshine 后生效。」点击「重启 Sunshine」先显示确认区，说明会断开正在进行的会话，用户可取消或确认。
- 自动保存失败时，在对应页反馈区显示具体原因并保留输入。其他有效改动仍可保存。返回或退出时如果还有未保存的改动，先确认是否放弃，取消后留在当前页。
- Windows 的「远控画面来源」和「远控时的本地显示器」分别设置。默认按原有显示设置并保留本地显示器。选择虚拟显示器后才可以关闭所有本地显示器，切回原有显示设置时恢复默认。原型中的虚拟显示器为演示数据。实际设备没有受信任的虚拟显示器时，在对应控件附近提示用户先在 Windows 启用它。[Windows 远控显示](windows.md#远控显示)

## 未登录时的引导

- Aurora 的设备身份认证依赖 Tailscale。未登录时，「我的设备」显示「登录后连接设备」和「前往登录」，局域网及异地设备统一锁定。设备列表与连接操作在登录后恢复。

- 正式应用在浏览器打开 Tailscale 官方登录页。原型在账户页模拟登录成功，再点「查看设备」可看到演示中的局域网和异地设备。

## Tailscale 账户

[Windows 账户页](screenshots/tailscale-runtime/windows-builtin.png) · [纯图标窄侧栏](screenshots/tailscale-runtime/compact.png)

macOS 使用内置 Tailscale。Windows 已安装系统客户端时可选择运行方式。系统模式下，点击当前账号的头像、姓名或邮箱可展开已保存账号。两种运行方式分别保留登录状态。切换成功后，窗口中央的轻提示约 3 秒自动淡出。[运行方式与账号切换](tailscale-runtime.md)

- 登录后，侧栏账户入口第一行优先显示账号的显示名，缺失时显示登录名。两者都缺失时显示当前网络名。第二行在登录名为 `用户名@github` 时显示「GitHub」，其余显示「Tailscale」。纯图标窄侧栏通过悬停提示和无障碍标签提供这两行信息。[Tailscale 账号格式](https://tailscale.com/docs/reference/syntax/policy-file#reference-users)
- 头像缺失或加载失败时，用账号名首字填充同尺寸的圆形占位。
- 文字头像使用独立的字色和圆底色。默认、选中、悬停、键盘聚焦时，这两种颜色保持一致。账户名称与导航项底色沿用侧栏的选中样式。
- 未登录时提供「登录 Tailscale」。内置节点未启动时可在 Aurora 里启动。暂停时可「恢复连接」。等待批准、正在启动和状态未知时，在原位置显示原因，保留刷新入口。未连接时入口显示 Tailscale 九点标志和当前状态。
- 已连接时，同一张卡片显示账户名、邮箱、所属网络和本机 Tailscale 地址，连接状态紧挨着账户名。「退出登录」在卡片右上方，使用 Lucide 退出图标，常态文字和图标与刷新按钮共用灰蓝色。设备列表通过侧栏「我的设备」进入。
- 标题右侧的刷新图标重新检查 Tailscale 状态。「连接帮助」按需展开，说明两台设备如何加入同一网络，以及设备在线时如何排查 Sunshine。
- 原型中的账户是林小满（xiaoman.lin@example.com），网络为 aurora-demo，头像为生成的演示插画。登录与退出只切换演示状态。

### 退出登录确认

点「退出登录」后，在整个应用窗口的中心弹出确认框，遮罩覆盖标题栏、侧栏和内容区。弹窗标题为「要退出登录吗？」，正文说明退出后本机会断开 Tailscale 网络，重新登录后才能连接设备。底部右侧依次放「取消」和浅红色的「退出登录」。

焦点默认落在「取消」，Tab 在两项操作之间切换。弹窗打开时，背景不可操作。「取消」或 Esc 收起弹窗，并把焦点交还给原入口。确认后账户页和侧栏状态同步更新，账户名、邮箱和所属网络收起，焦点移到「登录 Tailscale」。[Windows 退出确认截图](screenshots/components/account-logout-confirm.png) · [macOS 退出确认截图](screenshots/macos/18-account-logout-confirm.png)

## 控件与反馈

图标按钮在悬停或键盘聚焦时提供名称，触发动作交给 Enter 或空格。滚动时主导航与当前页标题保持可用。状态色搭配文字或点形，禁用态与可操作态清楚区分。操作反馈靠近当前页面的任务区域，成功、失败和需确认的动作使用不同文案。刷新、检测和复制等操作只在触发后显示结果。会中断会话的操作先确认。

### 刷新提示

设备列表刷新、Sunshine 检测和 Tailscale 状态刷新进行时，原按钮的位置显示一个旋转的加载环。点击范围和周边布局保持原位，等待期间同一个按钮暂停重复触发。完成后恢复原图标，再展开结果提示。原型模拟约 700 ms 的等待，正式界面按实际操作状态结束加载。开启「减少动态效果」时，加载环静止，仍显示等待状态。未登录时「我的设备」只提供登录引导。[刷新加载状态](screenshots/components/refresh-loading.png)

设备列表刷新成功，以及确认 Sunshine 正在运行或 Tailscale 已连接时，结果提示在完成后显示 **3 秒**，然后自动收起。再次刷新成功会重新计时。刷新失败、服务未运行或等待登录等需要处理的结果保留在对应操作附近。提示收起后，设备与服务的状态标记仍可查看。

提示区域在 **240 ms** 内从零高度展开，文字稍后淡入，下面的内容跟随区域高度下移。收起时文字淡出，区域在 **240 ms** 内回到零高度，下面的内容连续向上补齐。几条连续的刷新结果沿用同一提示位置并重新计时。系统开启「减少动态效果」时，提示和布局即时切换。

# 布局、对齐与距离

所有尺寸均为原型在 100% 缩放下的逻辑像素。对齐以界面元素的矩形边界为准，有透明边的图标再单独检查可见轮廓。窗口宽度下文指原型自身的宽度，浏览器预览还会留出外部边距。

窗口、卡片和控件的圆角统一见[圆角规范](visual-guidelines.md#圆角规范)。

## 窗口与导航

- Windows 标题栏高 **52 px**，与侧边栏共用一块浅蓝灰背景，交接处连续。Windows 和 macOS 的主内容区在普通、最大化和全屏状态下均保持顶部两角 **12 px** 圆角、底部两角直角，距窗口右侧和底部内缘各 **3 px**。窗口外边线 **1 px**，普通窗口的外框圆角为 **13 px**，最大化和全屏时外框四角为直角。
- 品牌从窗口内缘起留 **12 px**。主图标使用 **32 × 32 px** 占位，与标题文字间隔 **3 px**。Windows 标题栏把 ICO 的可见轮廓缩到约 **24 × 24 px**，贴占位右缘，保留文字起点和图文间距。macOS 标题栏的透明图可见轮廓约 **21 × 21 px**。两版图标占位均向下微调 **1 px**，与标题文字视觉居中。
- 标题写作 **Aurora远程桌面**，中间无空格。英文用 Segoe UI **15 px / 20 px**，中文用 Microsoft YaHei UI **14 px / 20 px**，均为 **600** 字重，共用基线。排版时按实际字形检查两段文字的重心，尤其留意 Aurora 的字母没有下伸部。
- 带文字的侧栏按钮高至少 **50 px**、圆角 **7 px**，相邻导航项间隔 **2 px**。纯图标侧栏按钮高至少 **38 px**，相邻间隔 **4 px**。侧栏顶部留 **13 px**。文字和图标共用垂直中心，常规尺寸下图标占位与文字之间留 **14 px**。
- 「更多」贴住侧栏底部，「设置」在正上方，两项的点击范围左右对齐。以侧栏内缘为起点，带文字的侧栏左、下均为 **13 px**，纯图标侧栏左、下均为 **4 px**。度量按钮边距时取灰底矩形的边缘。Tailscale 账户、「我的设备」和「本机被控」之间等距，带文字时为 **2 px**，纯图标时为 **4 px**。侧栏头像为 24 × 24 px，圆心对齐图标列中心，名字与导航文字起点对齐。账户面板头像为 40 × 40 px。

### 侧边栏宽度

Windows 和 macOS 的侧栏上限为 **184 px**，普通窗口和最大化均沿用此宽度。文字导航用 **14 px** 字号。普通线框图标沿用 16 px 占位，绘制倍率由 1.25 提到 1.4，约增加 12%。Tailscale 保留原尺寸。带文字的侧栏中，选中框距侧栏左缘 **13 px**，图标布局盒距选中框左缘 **12 px**，合计距侧栏左缘 **25 px**。未选中按钮沿用同一位置。可见轮廓受各图标透明边影响，按布局盒统一定位。

| 窗口宽度 | 侧栏宽度 | 导航显示 |
| --- | ---: | --- |
| 大于 650 px | 184 px | 图标与文字 |
| 大于 470 px、至 650 px | 144 px | 图标与文字 |
| 470 px 及以下 | 43 px | 居中的图标，保留可读名称 |

右侧内容区随窗口伸缩和换行。窗口变窄时，侧栏按上表收窄，给内容区留出空间。

按参考截图的可见像素比较，两边导航文字均约高 17–18 px，对应字号倍率约 **1.00×**。参考侧栏普通图标约宽 23 px，Aurora 约宽 21 px，约 **1.10×**。相邻导航项中心间距约 65 px 对 53 px，约 **1.23×**。按截图中 Aurora 的 125% 比例折合为 **52 px** 逻辑行距，由 50 px 按钮加 2 px 间隔组成。

桌面「更多」的左、下边距均为 **13 px**，计入窗口 **1 px** 边线后，两边距窗口外缘均为 **14 px**。纯图标侧栏的「更多」距窗口外缘左、下各 **5 px**。参看[侧栏截图](screenshots/components/navigation.png)及[侧栏底部特写](screenshots/components/settings-inset.png)。

macOS 方案共享内容区的尺寸与交互原则。窗口控制灯在左侧，品牌标题与图标在右侧，标题栏高度采用 **52 px**。左侧控制灯的起点距窗口内缘 15 px，直径 12 px，灯间距 8 px。右侧品牌距窗口内缘 12 px。

## 页面与面板

- 「我的设备」「本机被控」「设置」「全部配置项」「Tailscale 账户」使用同一级大标题。标题左边缘与卡片、列表及标签栏的外边缘对齐。鼠标环境的页头高至少 **34 px**，触屏环境为 **44 px**。刷新与返回按钮沿标题行垂直居中。
- 常规页面大标题为 **26 px**，约为侧栏 14 px 文字的 **1.86 倍**。两个平台的各页沿用同一标题起点，页面间核对标题文字盒的上下与左右位置。最窄内容布局使用 21 px 标题字号和 6 px 页头控件间隙，标题与返回按钮能保持在同一行。
- 页头到内容的常规间距 **15 px**。「设置」与「全部配置项」标题下方先进入标签栏，间距 **6 px**，标签栏到后续内容 **11 px**。
- 白色普通面板用 **11 px** 圆角和 **1 px** 描边。组间距以 **12 px** 为起点。设置行最少 **45 px**，组标题行 **46 px**，内容左右通常内缩 **14 px**，窄界面降到 **8 px**。表单行让标签与输入、开关沿垂直中心对齐，同类控件右侧对线。
- 面板图标和文字共用垂直中心，间距 **10 px**。「这台电脑」线框和 Tailscale 九点标志均以 **28 × 28 px 可见轮廓**为准。线框 SVG 收紧 viewBox，两枚图标使用同样大小的 SVG 遮罩。核对缩放时量图形实际边界，并把 Tailscale 外圈浅灰圆点计入。

常用设置、应用设置和全部配置项的组内行靠行高、对齐和留白区分。组标题、表单行与底部操作区默认连续排布，组与组用独立面板和间距区分。[设置和配置的分隔线](visual-guidelines.md#设置和配置的分隔线)

「远控显示」与「常用设置」的组标题复用同样的标题行高度和内缩。标题与首行控件根据同类分组对齐，面板之间保留原有间距。标准按钮先按内容盒居中，再用中英文字的可见轮廓检查上下留白，尤其核对 125% 缩放下的「登录 Tailscale」「前往登录」和「重启 Sunshine」。

## 设备卡片

- 设备内容区至 **580 px** 为一列，超过 **580 px** 为两列，达到 **1000 px** 为三列，达到 **1450 px** 为四列。列数按内容区宽度计算，卡片间隔 **14 px**。[四列截图](screenshots/pages/20-devices-four-columns.png)
- 壁纸和白色操作栏共用 **14 px** 外圆角与 **1 px** 描边。壁纸宽高比 **1.88∶1**，高度至少 **176 px**。状态在左上，两边各留 **11 px**。信息在左下，左右通常留 **14 px**、底部 **12 px**。
- 设备名用 **17 px** 字号，下方留 **4 px** 接地址。地址一般用 **12 px / 18 px**。局域网和 Tailscale 地址在同一行，显示实际存在的地址。窄卡将字体降为 **11 px**，缩短地址间距并省略中间竖线。
- 白色操作栏由四个等宽功能区和右侧的「更多工具」按钮组成，高度至少 **45 px**，功能区用短细竖线分开。卡片内容宽度不超过 **325 px** 时图标置于文字上方。至 **250 px** 时「更多工具」列宽从 **34 px** 缩到 **29 px**，壁纸信息左右留白减为 **8 px**。参看[设备卡片截图](screenshots/components/device-card.png)。

## 标签与滚动

- 「设置」与「全部配置项」使用同一套标签视觉。最小占位 **40 × 40 px**，选中线居中，宽 **18 px**、高 **3 px**，距标签下沿 **2 px**。标签间距随窗口宽度变化，取宽度的 **2.5%**，下限 **6 px**、上限 **24 px**。
- 每个设置子板块用独立白色面板。切换和滚动时保留标题及标签位置。设备卡片列表与应用设置均把竖向滚动条放在内容区最右侧，预留滚动槽，避免滚动条出现时内容整体偏移。
- 「全部配置项」的搜索框在分类栏右边，最窄宽度换至下一行。核对操作范围时，用按钮盒的边界验证左右留白，再用键盘检查焦点框能完整显示。

## 新增内容如何对齐

| 新增位置 | 对齐参照 |
| --- | --- |
| 卡片外的页面级状态或说明 | 可见文字左缘对齐该页标题和卡片外缘。 |
| 卡片里的状态、组标题、表单标签和操作 | 沿用卡片的内容左缘、内边距和行高。同一列的可见文字共用起点。 |
| 同行的蓝字操作或文字与图标 | 操作文字共用基线，图标与文字行垂直居中。用同一容器的间距排布多个操作。 |
| 靠右的输入框、开关和按钮 | 对齐同组控件的右边缘。窄窗换行后继续沿用该组的左右边缘和行间距。 |

以 Windows「独立 Sunshine（参考）」场景中的「已登录 · 凭据保存在 Windows 凭据管理器」「打开 Sunshine 原版设置」「忘记已保存的登录」为例。若都作为卡片外的页面级内容，状态与第一个操作的**可见文字左缘**应对齐页面内容线，两个操作在同一行共用基线。若将凭据相关状态与操作收入一个卡片，则改用该卡片的内容线。验收时同时量按钮的可点区域和文字的可见起点，检查默认、悬停及键盘焦点。

## 新界面的对齐校验

1. 先对齐页面标题、标签栏和第一张内容卡片的左外缘，再核对标题行的垂直中心。
2. 沿用同类面板的行高、内边距、圆角和分组间距。空间不足或图形自身有透明边时，再做局部调整。
3. 检查点击范围与高亮范围是否重合。贴两条边的同一按钮应共用一个边距值。品牌和图标额外检查可见轮廓。
4. 在桌面、窄窗和触屏下检查截字、折行、操作区域和滚动。让滚动条出现，再复核最窄宽度及所有页面的标题起点。

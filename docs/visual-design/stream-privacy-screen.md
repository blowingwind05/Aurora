# 串流隐私屏保

[打开交互原型](aurora-stream-preview.html) · [串流窗口规格](stream-session.md)

## 从控制中心进入

已连接后进入「控制中心 → 安全 → 隐私保护」。这里显示被控设备当前已确认的保护模式，并提供「设置隐私屏保」。Windows 标准版、Windows UIAccess 测试版和 macOS 共用该入口、文字、状态及编辑器。命令是否可用以当前被控端返回的能力为准。

| 操作 | 结果 |
| --- | --- |
| 选择「关闭」「关闭显示器」或「隐私屏保」 | 立即向当前被控设备提交模式切换。等待远端确认时显示加载环和「正在切换…」，保留上一次确认的状态。成功后显示新模式。 |
| 点「设置隐私屏保」 | 在串流窗口内打开样式编辑器，页头显示当前被控设备名称。 |
| 选择预设、导入图片、点「大图预览」 | 在主控端检查草稿的取景与显示效果。被控端继续使用当前已保存样式及当前保护模式。 |
| 点「保存样式」 | 将样式同步到页头所示的被控设备。保护已经开启时，远端确认后用新样式替换当前画面。保护关闭或处于关屏模式时，样式在下一次开启隐私屏保时使用。 |
| 点「恢复默认」 | 将草稿选中项恢复为该设备的内置默认样式。预览随之更新，保存后才同步。 |

编辑器页头显示「设置隐私屏保」和「被控设备 · 设备名」。左侧以 16∶9 画框显示带「本地预览」标签的草稿，右侧放八张内置壁纸和「导入图片」。底部左侧放「恢复默认」，右侧放「大图预览」和「保存样式」。保存前的选择用浅蓝和勾标识，已确认样式在安全页以「已保存样式」显示。编辑器使用 Aurora 的白底 R13、主次按钮 R7、图片卡 R11。预设取自仓库的八张东方主题壁纸，原型使用[相同素材](assets/README.md#设备壁纸)。晴空山谷是原型里的示例默认样式。

导入后显示文件名并先完成本地解码，保留之前的草稿直到预览可用。输入格式和大小随被控端能力呈现。无法打开、解码或上传时，在对应位置用简短的原因引导重新选择。图片在预览内保持比例并取景填满画框。大图预览使用同一编辑器，点「返回设置」回到选择位置。预览会话与实际被控屏的显示状态分别呈现。

## 保存与状态

| 场景 | 用户看到的结果 |
| --- | --- |
| 未修改、重新选中已保存的样式 | 显示与被控端确认内容相同的预览，保存按钮禁用。 |
| 保存中 | 主按钮内转圈并写「正在保存…」，编辑暂缓，防止重复提交。目标始终是打开编辑器时显示的同一台设备。 |
| 保存成功 | 显示「已保存到 设备名」，更新已保存样式。预览保留在编辑器中，可继续选择。 |
| 被控端明确拒绝、导入或传输失败 | 保留已确认样式和草稿，显示原因，保存按钮恢复为「重试保存」。正在遮挡的会话继续用此前已确认的样式。 |
| 保存时断线或远端确认丢失 | 显示「保存结果待确认」，释放编辑器的等待。重连同一设备时先读取远端确认的样式与隐私状态，避免误报保存成功。 |
| 退出编辑器 | 放弃尚未提交的编辑。返回安全页；从全屏打开时回到原来的全屏串流。 |
| 退出串流或被控端离线 | 会话的遮挡生命周期沿用隐私保护逻辑。已确认的样式继续属于这台被控设备。重连以远端实际状态为准。 |

远端支持切换隐私模式但只提供默认屏保时，「设置隐私屏保」置灰并说明「被控端暂不支持自定义屏保」。不支持隐私保护时，安全页显示原因，模式和设置均置灰。支持自定义的系统版、UIAccess 版和 macOS 都使用同样的选择、预览、保存和反馈。各端已有的关屏模式继续按被控端报告的能力呈现。

窄窗把预览摆在预设上方，剩余内容可以滚动，底部操作保持可见。全屏从顶边唤出控制中心后在会话窗内打开编辑器，鼠标交还本地 UI，退出编辑器后还原控制中心和安全页焦点。对话框内的 Esc 收起编辑器，保存期间先等待当前请求结束或断线反馈。

# Aurora 视觉与交互规范

[项目首页](../README.md) · [贡献指南](../CONTRIBUTING.md)

Windows 与 macOS 共用浅色工作区、面板层级和交互状态。尺寸以逻辑像素计。实现时优先复用[桌面样式](../desktop/AuroraApp.axaml)、[视觉控件](../desktop/AuroraVisual.cs)和[现有布局](../desktop/AuroraWindow.axaml)。

## 颜色与字体

| 用途 | 色值 |
| --- | --- |
| 顶栏、导航背景 | `#EDF1F8` |
| 主工作区背景 | `#F9FAFC` |
| 面板、表单和菜单 | `#FFFFFF` |
| 主文字和次文字 | `#19283F`、`#526176` |
| 窗口和面板描边 | `#C6D1E0`、`#DBE2ED` |
| 短分隔线 | `#E7EBF3` |
| 主操作、选中文字、键盘焦点 | `#087CF5` |
| 备用文字操作、状态点 | `#2350B4`、`#244FC5` |
| 导航选中、导航与设备工具悬停 | `#E2E7EF`、`#E8EDF4` |

Windows 英文使用 Segoe UI，中文优先 Microsoft YaHei UI。macOS 采用系统字体与 PingFang SC。品牌文字为「Aurora远程桌面」。页面标题通常为 26 px，最窄布局为 21 px。导航文字为 14 px，选中标签和卡片组标题为 15 px、650 字重，设备名为 17 px，状态和设备地址通常为 12 px。

## 主窗口

主窗口标题栏高 52 px，侧栏与标题栏连续铺底。Windows 品牌在左、窗控在右；macOS 原生红黄绿窗控在左、品牌在右。普通窗口外框为 13 px 圆角和 1 px 描边，最大化和全屏时外框使用直角。

| 窗口宽度 | 侧栏宽度 | 导航 |
| --- | ---: | --- |
| 大于 650 px | 184 px | 图标与文字 |
| 大于 470 px、至 650 px | 144 px | 图标与文字 |
| 470 px 及以下 | 43 px | 图标与可读名称 |

有文字的导航行高 50 px，行距 2 px。选中框距侧栏左缘 13 px，图标布局盒距选中框左缘 12 px。底部「设置」和「更多」左右对齐，有文字时距侧栏左、下各 13 px，纯图标时各 4 px。页面标题、卡片与表单共用内容左缘，同行控件沿视觉中心对齐。刷新和返回位于标题行右侧。

## 设备卡片

[设备卡](../desktop/DeviceCard.cs)按主内容区宽度排布。至 580 px 为一列，超过 580 px 为两列，达到 1000 px 为三列，达到 1450 px 为四列。卡片间隔 14 px，外圆角 14 px，壁纸视口宽高比约 1.88∶1，最小高 176 px。

设备状态在左上，设备名和地址在左下。使用真实状态表达在线、离线及在线但串流不可用。在壁纸上铺底部暗化渐变，保持白色设备文字可读。离线壁纸叠 30% 的 `#FBFBFB`，灰雾位于暗渐变下方；白色工具栏与壁纸分开。

缓存中的远端真实壁纸优先。没有缓存时从[默认壁纸目录](../desktop/Assets/Wallpapers/)循序取图，顺序为晴空山谷、林间小径、花树下、银杏湖畔、冰湖钢琴、冰湖手风琴、向日葵花田、逆光云海。花树下使用 1024 × 634 px 的显示素材。

工具栏从左到右排列文件传输、观看模式、终端、端口映射和「更多工具」。操作可用性由设备能力决定。重启和关机在「更多工具」内，先用含设备名的确认对话框说明影响，默认聚焦「取消」。

## 设置与控件

「设置」按画质、音频、通用、高级设置分组。「本机被控」使用独立卡片展示宿主状态、地址、开关以及相应的管理入口。表单通常用 11 px 卡片圆角、14 px 内边距、12 px 组间距；窄窗内边距可收至 8 px。组标题位于卡片内，表单行至少高 45 px。组内层次靠留白和标题区分。

| 状态 | 验收口径 |
| --- | --- |
| 导航、设备工具悬停 | 背景 `#E8EDF4`，普通图标加深。 |
| 刷新、检测、复制等裸图标 | 常态灰蓝，悬停转 `#087CF5`。图标提供可读名称及键盘焦点。 |
| 次级文字操作 | 常态 `#526176`，悬停与聚焦用 `#087CF5`，点击区沿用原有对齐。 |
| 备用蓝字按钮 | 常态透明。悬停时整个点击区铺 `#EDF2FC`，文字与箭头保持 `#2350B4`。 |
| 键盘焦点 | 2 px 蓝框，与鼠标悬停独立；卡片内焦点避免被圆角裁切。 |
| 开关 | 32 × 18 px，圆点 12 px。开启态用蓝底和右侧白点；关闭态用 `#F0F3F7` 底、`#8E9BB0` 边框及左侧 `#6D7C92` 圆点；禁用态整体不透明度为 55%。 |

下拉字段展开时保留字段对齐和可读选中项。覆盖方向键浏览、Enter 确认和 Esc 关闭。字段说明靠近对应控件。错误反馈用于说明未完成的动作和可采取的下一步。

## 串流窗口

使用独立窗口，视频区从顶栏底边开始。窗口化顶栏采用连续的浅蓝灰背景，设计高 44 px。设备名、连接状态和会话控件共用一行。Mac 保留左侧原生红黄绿按钮，右端使用 Aurora 品牌图标。控制中心容纳会话内操作；隐私屏保以被控端的回报更新状态。释放鼠标和统计等快捷操作放进相应菜单。

连接中、出画和失败沿用同一布局。失败时给出具体原因，重试沿用会话的入口。桌面指针模式下，鼠标离开画面区域时回到本机操作。需要锁定鼠标的会话提供明确的释放入口。

连接后可以从顶栏的连接状态展开详情。浮层宽 292 px，优先显示网络往返延迟，其余行仅列出当前会话的可用指标。

全屏出画后，控制中心使用画面右上角的 40 × 40 px 悬浮按钮，与边缘保持 14 px。菜单提供退出全屏和断开连接。Windows 窗口的还原按钮使用重叠方框。

显示器入口和连接详情使用会话实际提供的数据。虚拟显示器的新增按钮和页签关闭按钮依赖被控端的创建、切换和释放能力。显示器变化保持视频区域和系统窗控位置稳定。

## 图标与验收

- 产品图标按用途选择。Windows 应用图标使用[多尺寸 ICO](../desktop/Assets/Aurora.ico)，macOS 访达与程序坞使用 [Aurora.icns](../desktop/Platform/Mac/Assets/Aurora.icns)，菜单栏使用单色模板资源。 [Mac 主图标规格](visual-decisions.md)
- 界面线框图标优先复用仓库内已有的 Lucide 几何。新增资产记录来源与许可；核对透明图标的可见轮廓、同类控件的文字基线和点击范围。 [第三方声明](../THIRD-PARTY-NOTICES.txt)
- 提交界面改动时核对宽窗、窄窗、最大化和滚动状态。按钮验收纯中文、中英混排和有下伸字母的英文，覆盖常用 DPI、悬停、禁用及键盘焦点。只有 AppKit 实际运行的观察用于判断 Mac 原生标题栏和系统材质。 [Windows 检查命令](../tests/windows-visual/README.md)
